서비스의 위치 기능

3. 개인위치정보의 수집 방법과 범위

  1. 이용자가 도움 요청을 실행할 때 Android 위치 권한이 이미 허용되어 있으면 앱이 Android 위치 기능을 통해 해당 시점의 현재 위치를 한 번 확인합니다.
  2. 위치 권한이 허용되어 있지 않은 경우 Android의 위치 권한 허용 절차를 진행하며, 이용자가 권한을 허용한 경우 현재 위치를 확인합니다.
  3. 서비스는 도움 요청 실행 시점의 위치만 확인하며, 위치 권한을 허용한 뒤에도 상시적으로 위치를 수집하지 않습니다.
  4. 정확한 위치 또는 대략적인 위치 중 이용자가 Android에서 허용한 범위와 단말기 환경에 따라 위치의 정확도가 달라질 수 있습니다.
  5. 위치 권한을 거부하거나 위치 서비스가 꺼져 있거나 위치 취득에 실패한 경우에도 위치정보 없이 도움 요청을 이용할 수 있으나, 보호자 지도에는 위치가 표시되지 않습니다.
  6. 정확한 위도·경도는 도움 요청 푸시 알림(FCM)에 포함하지 않습니다. 연결된 활성 보호자가 앱에서 도움 요청을 확인할 때 인증 절차를 거쳐 서버에 저장된 현재 진행 중 도움 요청의 위치를 조회하도록 처리합니다.
  7. 운영자는 위치정보를 광고, 이용자 분석, 이동경로 작성 또는 제3자 판매 목적으로 사용하지 않습니다.

4. 개인위치정보의 제3자 제공

운영자는 개인위치정보를 원칙적으로 외부에 제공하지 않습니다. 다만 대상자의 도움 요청에 대응하기 위해 도움 요청 당시 서비스에 연결된 활성 보호자가 위치정보를 확인할 수 있도록 다음과 같이 제공합니다.

제공받는 자제공 정보제공 목적·조건
도움 요청 당시 대상자와 연결된 활성 보호자(복수일 수 있음)도움 요청 시 확인된 현재 위치, 측정 시각·정확도대상자가 도움 요청을 실행하고 위치가 정상적으로 취득된 경우, 도움 요청 대응을 위해 앱에서 확인할 수 있도록 제공
관계기관법령상 요구되는 범위의 위치정보 또는 사실확인자료법률에 근거한 수사·재판·긴급구조 등 적법한 요청이 있는 경우

서비스는 대상자의 위치정보 이용 동의 및 Android 위치 권한 허용을 전제로 위치 기능을 제공합니다. 실제 위치가 취득된 도움 요청이 발생하면, 운영자는 연결된 활성 보호자에게 도움 요청 대응 목적으로 위치정보를 확인할 수 있도록 제공하고 대상자에게 위치정보 제공 사실을 SMS로 1회 통보합니다. 이 통보에는 제공받는 보호자에 관한 표시정보, 제공 목적과 통보 시각 등 필요한 정보가 포함되며 정확한 위도·경도는 SMS로 전송하지 않습니다. 보호자가 이후 도움 요청 화면이나 지도를 다시 열 때마다 별도의 SMS 통보를 반복하지 않습니다.

5. 개인위치정보의 처리위탁 및 국외 처리

운영자는 서비스 제공을 위해 Google LLC의 Firebase 및 Google Cloud 서비스를 사용하고, 위치정보 제공사실 SMS 통보를 위해 SOLAPI를 사용합니다. Cloud Firestore는 운영자가 설정한 asia-northeast3(서울) 리전에 저장하고 Cloud Functions도 같은 리전에서 서비스 로직을 처리합니다.

Firebase Authentication, FCM 및 Google의 보안·운영 지원 과정에서는 Google의 국제 인프라가 사용될 수 있습니다. 국외에서 처리될 수 있는 경우의 이전받는 자는 Google LLC 및 관련 처리자이며, 이전 국가에는 미국을 포함하여 Google이 서비스 제공·보안·지원에 사용하는 국가가 포함될 수 있습니다. 이전 시기·방법은 서비스 이용 과정에서 암호화된 네트워크를 통한 전송이며, 보유기간은 제2조에 따릅니다. 자세한 내용은 Firebase 개인정보 보호 및 보안 안내에서 확인할 수 있습니다.

사실확인자료에는 도움 요청 당시의 정확한 위도·경도 및 위치 정확도 값을 저장하지 않습니다. 또한 각 보호자가 도움 요청 화면이나 지도를 열 때마다 별도의 위치 조회이력을 반복적으로 생성하여 보관하지 않습니다.
